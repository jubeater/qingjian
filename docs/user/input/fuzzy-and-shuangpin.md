## 模糊音

九条：z/zh、c/ch、s/sh、n/l、f/h、l/r、an/ang、en/eng、in/ing。缺省全部关闭。

开启：输入法菜单「模糊音」子菜单勾选，或「设置 → 输入 → 模糊音」。开启 z/zh 后输入 `zi` 也出 知 / 之，开启 f/h 后输入 `kaiha` 也出 开发。
输入正确的词仍然优先，模糊匹配的词排在其后。韵母三条只对完整音节生效。

## 输入方案

「设置 → 输入」里是**两个独立的设置**：

| 设置 | 可选 |
| --- | --- |
| 拼音方案 | 全拼（缺省）、小鹤双拼、自然码、微软双拼、搜狗双拼、智能ABC、小浪双拼、首道双拼、拼音加加、紫光双拼，以及自己放入的双拼方案；大千注音、关 |
| 形码 | 关（缺省）、五笔（86 版），以及自己放入的形码方案 |

两边可以各自单开，也可以同时开——同时开着就是**混输**，见下一节。

中英切换始终是 `Shift`，与选哪套方案无关。全拼、双拼与注音都是「拼音」的读法，共用同一份词库、整句转换与学习数据；形码按编码查码表，走的是另一条路。
两个都关着时按全拼算，不会一个字都打不出。

## 双拼

九套方案：小鹤、自然码、微软、搜狗、智能ABC、小浪、首道、拼音加加、紫光。

双拼同样支持模糊音。开启 s/sh 后，自然码 / 微软 / 搜狗的 `sd`、小鹤的 `sl` 可以查到「双」，接着输入「人」的双拼码可以查到「双人」。这类声母与韵母原本拼不成合法音节的组合，只有对应模糊音规则开启后才参与查询；选词后按实际按键数清掉已上屏部分。

- 拼音行显示解出的全拼（`nihc` → `ni'hao`，小浪 `nihs` → `ni'hao`）。「设置 → 输入」打开「输入框显示按键」后，输入框里改为显示敲的键（`kdfa`），候选窗口的拼音行照旧显示全拼（`kai'fa`）。学习按全拼记录，切回全拼后同样受益。
- 零声母：小鹤 / 自然码写 `aa` `ai` `ah`（a、ai、ang）一族；微软 / 搜狗写 `o` + 韵母键（`oa` `ol` `oh`）；智能ABC 也写 `o` + 韵母键，但韵母键按它自己的表（ei 是 `oq` 不是 `oz`），且不认双写元音（`aa` 是 zha、`ee` 是 che）；紫光同样只写 `o` + 韵母键（`oa` `or` `oj`），不认双写元音与双写韵母；小浪写 `aa` `ai` `ah` `ao`、`uu`（e）、`ui`（ei）、`un`（en/eng）、`ur`（er）、`oo`（o）、`ou`（ou）。
- 微软 / 搜狗 / 紫光的 `;` 为 ing：输入拼音时末尾有落单的声母，`;` 作为拼音（`x;` → xing）；其他情况下仍为标点。
- 微软 / 搜狗的 ü 键为 `y`：`ny` / `ly` 输入女 / 绿，`jy` / `qy` / `xy` / `yy` 解为 ju / qu / xu / yu。其他方案也接受各自 ü 键与 j / q / x / y 的组合，但同键已有的合法读法优先（微软 `jv` 仍为 jue，小浪 `jv` 仍为 jing）。
- 智能ABC 翘舌声母以 `a` 为 zh、`e` 为 ch、`v` 为 sh（`ai` → zhi、`ei` → chi、`vi` → shi）。
- 小浪双拼翘舌声母以 `e` 为 zh、`i` 为 ch、`v` 为 sh；`x` 为 ü（`lx` → lv，`nx` → nv，`jx` → ju）；`v` 兼作韵母 uai 与 ing；未在键位表列出的韵母按原拼键输入（如 a/e/i/u 及 o 对 uo/o）。
- 首道双拼翘舌声母以 `v` 为 zh、`i` 为 ch、`e` 为 sh；零声母双写首字母或照全拼输入（`aa` `ai` `an` `ao` `oo` `ou` `en` `er`），ang 为 `ay`，e / ei / eng 以 `u` 引导（`ue` `ui` `uf`）；ue 在 `l`（`jl` → jue），üe 单独在 `b`（`lb` → lve）。
- 拼音加加双拼翘舌声母以 `v` 为 zh、`u` 为 ch、`i` 为 sh（ch / sh 与小鹤、自然码相反）；主排高频韵母 ai→S、ao→D、an→F、ang→G、ei→W、en→R、eng→T，ing 在 `q`；ü 在 `v`（`nv` 女、`lv` 绿），üe 在 `x`（`jx` → jue、`nx` → nüe）；零声母以双写为主（`aa` `as` `af`、`ee` `er` `eq`、`oo` `op`，注意 en 是 `er`、er 是 `eq`），也兼容 o 前缀（`oa` `oe`）；不用 `;` 键。
- 紫光双拼翘舌声母以 `u` 为 zh、`a` 为 ch、`i` 为 sh（`ui` → zhi、`ai` → chi、`ii` → shi，`a` 与 `i` 兼作韵母）；`;` 为 ing（`x;` → xing）；ü 在 `v`（`nv` 女、`lv` 绿），üe 与 ue、ui 同在 `n`（`jn` → jue、`yn` → yue、`gn` → gui）；零声母只写 `o` + 韵母键，不认双写元音（`aa` 是 cha）也不认双写韵母 `ii` `uu`（那是 shi、zhu）。
- 双拼下 v / u / i 均为音节键，[快捷输入](shortcuts.md) 中的算式与问字改为按住 `Shift` 输入：`Shift`+`V` 后接算式（`V1+2`），`Shift`+`U` 后接拼音或码点（`U4e00`），与搜狗、微软双拼一致。未输入拼音时才生效；模式键改过的，按改后的字母加 `Shift`。
- 全拼输入 `lue` / `nue` 与词库形式 `lve` / `nve` 等价；j / q / x / y 后的 `v` 也认（`tiqv` → 提取，与微软、搜狗一致），带韵母时同样可用（`xvexi` → 学习、`jvan` → 卷、`yvn` → 云）。双拼统一解为 `lve` / `nve`。
- 「嗯」按习惯用 `en` 输入（`enen` → 嗯嗯）；全拼下单独敲 `ng` 也出「嗯」，与其他拼音连写时请用 `en`。
- 已知限制：`lo` 与 `luo` 同键，解为 luo。小浪方案中 `en` 与 `eng` 同码（`un`），统一解为 `en`；`dia`/`dai` 同码解为 `dai`，`lia`/`lai` 同码解为 `lai`，`nen`/`niang` 同码解为 `niang`。首道方案中 `den`/`dia` 同码（`dk`），解为 `den`。

### 键位提示

记不住键位时，可以让候选窗口旁边显示当前方案的键盘（[自己放入的双拼方案](#自定义双拼方案)也一样）：每个键标着它的韵母，占键的翘舌声母（zh / ch / sh）标在右上角。敲了声母之后，能接着拼成音节的键变绿并写出那个音节，拼不出的键变暗。

在「设置 → 输入」的「键位提示」里选：

- 卡住时显示：敲到一半停顿一下，或者敲出拼不成音节的键时才出现，打得顺的时候看不到。出现之后这次输入一直留着，上屏后收起。
- 一直显示：输入时一直显示。

「键位提示大小」「键位提示透明度」两个滑块调键盘的大小与透明度，每格 5%。键盘放在候选窗口背向光标的一侧，放不下就挪到候选窗口左右或光标另一侧，不会盖住正在输入的那一行；哪儿都放不下时这次不显示。macOS 与 Windows 支持；Windows 上要用青简渲染器画候选窗口（缺省就是），改成系统绘制时不显示。

## 自定义双拼方案

键位不合手、或者想用的方案不在上面九套里，可以自己写一套。和[自定义形码方案](#自定义形码方案)放在同一个 `schemes` 文件夹里，每个方案一个子文件夹，文件夹名就是方案的标识（规则相同），里面只要一个 `scheme.toml`。`author`、`version`、`description`、`license` 这几项与形码方案相同，下面略去：

```toml
type = "shuangpin"     # 必须写，表示这是双拼方案
name = "我的小鹤"       # 设置与状态条里显示的名字，省略时用文件夹名
base = "xiaohe"        # 拿哪套内置方案当底子，只写要改的键；省略时从空白开始

[finals]               # 韵母键：键 = 韵母，一个键放几个韵母时写成列表
k = "uai"
";" = "ing"            # ; 要加引号

[initials]             # 翘舌声母：键 = zh / ch / sh
v = "zh"

[zero]                 # 零声母：音节 = 两键写法，几种写法时写成列表，第一种是主写法
ang = ["ah", "ag"]
```

- `base` 可以是 `xiaohe`（小鹤）、`ziranma`（自然码）、`microsoft`（微软）、`sogou`（搜狗）、`abc`（智能ABC）、`xiaolang`（小浪）、`shoudao`（首道）、`jiajia`（拼音加加）、`ziguang`（紫光）。
- 三张表都按「键」（零声母按音节）整条替换底子里的那一条。要把一个韵母挪到别的键，原来那个键也要重写，否则两个键都能打出它；写成空的（`k = ""`）就是撤掉这个键上的韵母。
- 声母键只放 zh、ch、sh，其余声母就是字母本身，所以不能放在 b、p、m 这类本身就是声母的键上。
- `;` 只能当韵母键（第二个键），和微软双拼的 ing 一样：前面有落单的声母时它是拼音，否则仍是标点。
- 写错了（键不是字母、韵母不存在、零声母写法不是两个键）的方案不会出现在设置里；有音节打不出来时照样能用，[运行日志](../help/data-and-logs.md#运行日志)里会列出是哪些。

放好之后切回设置窗口，在「设置 → 输入 → 拼音」里选它，内置双拼排在前面、自己的方案紧随其后。模糊音、「输入框显示按键」与内置双拼一样可用。暂不支持 Linux。

## 形码

随包提供 86 版五笔，也可以放入自己的形码方案（见下一节）。敲的是编码而不是读音，以五笔为例：`ggll` 出 一，`khlg` 出 中国，`gant` 出 开发。
候选框顶部原样显示敲的编码，不打乱成音节。

- 编码打到哪儿算哪儿，按该前缀查表。编码正好打全的词排在同前缀的更长编码词前面（这就是一级 / 二级 / 三级简码）。
- 空格上屏高亮候选，数字键选词，与拼音一致；候选旁的译文、词频学习与生词记录也照常。
- 这条路上没有拼音的那些能力：整句输入、简拼、模糊音、拼写纠错，以及 `v` / `u` / `i` 开头的[快捷输入](shortcuts.md)。
  这三个键在形码里是编码键，不再当模式键。
- 单用形码时把拼音方案设为「关」；那样连中英混输也没有，敲多长都是编码。

单用形码时另有几条规则：

- **满码唯一自动上屏**：编码敲满码长（五笔是 4 码），而且这个编码只对应一个词时，不用按空格，直接上屏。例如 `trwu` 直接上屏 我们；`khlg` 对应 中国、跑车、跨国 三个词，停下等待选择。
- **顶字**：编码已经敲满时再敲一个字母，先把高亮的候选上屏，这个字母作为下一个词编码的第一个字母。例如 `khlg` 之后接着敲 `trwu`，依次上屏 中国、我们。
- **标点上屏**：组句中敲逗号、句号这类标点，先上屏高亮候选，再接全角标点，不受「标点先上屏候选」设置影响。
- **空码清除**：编码查不到任何词时，按空格或标点只清掉编码，不把字母打进正文；需要字母时按 `Enter`。

前两条可以关：拼音方案为「关」时，「设置 → 输入」的「形码」下面有「满码唯一自动上屏」与「顶字」两个开关，按方案分别记住。方案作者也可以在[自定义方案](#自定义形码方案)里定缺省值。混输时这几条都不生效：满码之后的字母可能是在接着打拼音。

### 字根图

形码选了五笔（86）时，「设置 → 输入」里同样有「键位提示」：候选窗口旁边显示 86 版字根图，每个键上是它的全部字根（含变体），底下一行是键名与区位号。
弹出时机、大小与透明度和双拼的键位提示是同一组设置，见 [键位提示](#键位提示)。混输时显示字根图。自己放入的形码方案没有字根图，不显示键位提示。平台支持同双拼的键位提示。

## 自定义形码方案

在[本机文件](../help/data-and-logs.md#本机文件)的目录里建一个 `schemes` 文件夹（与[自定义双拼方案](#自定义双拼方案)共用），每个方案一个子文件夹，文件夹名就是方案的标识：只能用小写字母、数字、`-` 与 `_`，不能与拼音方案的写法（如 `xiaohe`、`pinyin`）重名。

```text
schemes/
└── huma/
    ├── scheme.toml   （方案说明，必须有）
    └── table.tsv     （码表）
```

码表是纯文本，每行「词 + 制表符 + 编码 + 制表符 + 词频」，词频可省略；`#` 开头的行是注释：

```text
一	ggll	90000
开发	gant	900
```

- 编码只能是英文字母，不区分大小写；编码里有其他符号的行会被跳过。
- 词组的编码需在码表里写全，青简不会由单字编码推出词组编码。
- 满码长度按码表里最常见的编码长度算（五笔是 4），个别更长的编码不影响；需要时可在 `scheme.toml` 里指定。

`scheme.toml` 必须有，没有它的文件夹不算方案。里面写名字、方案说明与两条规则，每一项都可省略，所以空文件也行：

```toml
name = "虎码"          # 设置与状态条里显示的名字，省略时用文件夹名
author = "某某"        # 作者
version = "1.0"       # 版本
description = "……"    # 一两句话说这套方案是什么
license = "CC-BY-4.0" # 许可，分享给别人时写清能不能再分发
table = "table.tsv"   # 码表文件名，省略时为 table.tsv
auto_commit = true    # 满码唯一自动上屏的缺省值，省略时为开
top = true            # 顶字的缺省值，省略时为开
code_length = 4       # 满码几个字母，省略时按码表里最常见的编码长度
```

`auto_commit` 与 `top` 只是缺省值，用户在设置里改过的以设置为准。

放好之后重新打开设置，在「设置 → 输入 → 形码」里选它。文件夹名为 `wubi86` 的方案会替换随包的五笔，可以用来换一份五笔码表。

## 混输（形码 + 拼音）

**拼音方案与形码同时开着**就是这样。敲编码与敲拼音都认，形码打不出的字直接打拼音。以五笔为例：

```text
gant     → 开发          （编码）
nihao    → 你好          （编码查不到，落到拼音）
ggll     → 一            （编码切不成音节，拼音那半条自动让位）
woxiangxuehao → 我想学好  （第 5 个字母起五笔已经查不到东西，只剩拼音）
```

- **编码打全的形码词排在最前，其次是拼音候选，只敲了编码前缀的形码词排在拼音之后**：`ga` 第一个是 开，`kai` 第一个仍是拼音的 开（编码以 `kai` 开头的词在后面）。
- 五笔编码最长 4 位，所以**敲到第 5 个字母时自动只剩拼音**，不用手动切；其他方案按各自的码长算。
- 同一个词两边都命中时只出现一次。
- 中英混输（句末夹英文词）只在拼音那半条路上，编码本身不参与。
- 混输下小写 `v` / `u` / `i` 是编码键，[快捷输入](shortcuts.md) 的算式与问字同双拼一样改为按住 `Shift` 输入（`V1+2`、`U4e00`）；超过码长的输入只可能是拼音，拼写纠错照常。

反过来（主要用拼音、偶尔用形码）也能用，只是一级 / 二级简码（五笔里 `wo` 是 伙）会排在拼音首选前面——不想要就把形码关掉。
