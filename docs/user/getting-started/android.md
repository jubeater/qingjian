青简 Android 版处于开发阶段，尚未提供安装包，需要从源码构建，步骤见源码仓库 `apps/android` 目录的说明。
拼音转换、词库、学习与统计全部在手机上完成；只有快捷翻译、翻译选中的文字、释义兜底与云联想需要联网，且需自行填写 AI 服务商。

## 启用

打开「青简」应用，首页上方的提示卡给出两步：在系统设置中启用青简，再把青简切换为当前输入法。
首页的「试一试」输入框可用于直接试打，「今日字数」统计当天上屏的汉字数。

## 键盘

- 点工具栏的键盘图标可选择输入方式：拼音 9 键、拼音 26 键、双拼、五笔（86 版）、注音（大千）、英文 26 键、日语罗马音（测试版）。
- 中英键按下在中文与另一种语言之间切换，键角小字是将要切到的语言；长按中英键可选择其他语言。
- 九宫格左侧一列在输入拼音时列出同键的拼音，点击可定下这个音节；不在输入时放常用标点。
- 「123」进数字键盘；中文键盘的「符」打开分类符号，英文键盘的「!?#」打开常用符号页。
- 长按空格左右滑动可移动光标；回车键按输入框的用途显示「发送」「搜索」「前往」等。
- 密码、网址、邮箱输入框中按键直接上屏，不进入拼音输入，也不学习。
- 应用标为私密的输入框（如浏览器的无痕标签页）中照常打字，但不学习输入习惯、不记生词，快捷翻译、释义兜底与云联想也不发送。

## 候选与译词

- 候选下方附带学习语言的译词，橙色表示生词，见 [译词与生词](../learning/translation.md)。学习语言可选英语、日语、西班牙语、越南语、德语，或不显示译词。
- 长按一个候选弹出它的译词，手指滑到某条译词上松开，上屏这条译词；滑出气泡则取消。
- 能删除的候选（自己造的词、学过的词、英文词）在气泡末尾多一项「删除」：删掉自己造的词，或清除对这个词的学习记录。没有译词的候选，气泡中只有「删除」，需要手指往上滑进气泡才会选中。
- 候选条右端的 ⌄ 展开全部候选。
- 一段拼音分几次选时，先选的词留在输入框里，整段选完再一起上屏；选错了按删除键撤回上一次选择，重新选。按回车连同剩下的拼音原样上屏。不想这样可在键盘设置关掉「分次选词先不上屏」。

## 日期与算式

- 输入 `rq`、`sj`、`xq` 得到当天日期、当前时间和星期；输入 `riqi`、`shijian`、`xingqi` 时，同样的写法紧跟在「日期」「时间」「星期」之后。
- 九宫格中，`77` 这类数字不当作 `rq`；在左侧拼音列依次点 r、q 后才出日期。`7474`（riqi）出「日期」时同样带日期写法。
- 全键盘输入 `v` 后点「123」，接着输入算式，如 `v1+2`，候选给出 `3` 与 `1+2=3`；`v123` 给出中文数字与金额写法。
- 在数字键盘上直接输入 `3+4` 上屏后，候选条给出 `7` 与 `3+4=7`：点 `7` 把算式换成结果，点 `3+4=7` 在后面补上 `=7`。输入 `3×4=` 后候选给出 `12`。日期（`2026-10-19`）和电话号码不当作算式。

## 生词本与统计

- 「生词本」页列出打字时候选旁见过的学习语言译词，最近见到的在前。右上方的语言可直接改学习语言。
- 搜索框按词、对应的中文或例句查找，不分大小写，可与筛选一起用。
- 可按「生词 / 近 7 天新见 / 认识了」筛选（近 7 天含今天，滚动计算，不在周一或周日归零）；英语按 A1–C2、日语按 N5–N1 分级筛选。
- 点一个词查看它对应的中文、例句与次数，可标「认识了」（候选里不再标成生词）或从生词本删除。
- 首页上方是输入统计：今日字数（打字够半分钟时附今天速度）、近 7 天与累计字数，最近 30 天每天的字数，以及首选率、一次打对、每字键数和有输入的天数。没有输入时显示 0 或「—」。
- 点首页任一张统计卡（或「我的」页的累计卡）打开统计详情：今天、近 7 天、本月与累计的字数，过去 24 小时与最近 30 天的柱状图，最多的一天、速度、首选率、一次打对与平均码长，以及学习语言各级词汇的进度。

## 剪贴板与常用语

- 工具栏的剪贴板图标打开剪贴板与常用语。复制过的文字和图片保存在手机上，点击即上屏；密码管理器复制的密码不保存。
- 剪贴板中的一条可加为常用语，或用「拆词」按词选出其中一部分。
- 常用语可分组，可设置输入码；输入输入码即可在候选中直接得到这条常用语。
- 「键盘设置 → 剪贴板」可关闭记录，或设置最多保存的条数。

## 词库

「我的 → 词库」（或「键盘设置 → 输入 → 词库」）：

- 领域词库：法律、医学、地名、成语、诗词名句、IT 与计算机、财经、饮食、动物、汽车、历史人物，随安装包附带，逐本开关。成语缺省开启。
- 导入词库：点「导入词库」，在系统文件选择器中选择文件，可多选。支持青简 TSV（每行「词、拼音、词频」以 Tab 分隔，拼音音节间以空格分隔）、Rime 的 `.dict.yaml` 与青简 `.qj`，格式同 [词库](../settings/dictionaries.md)。导入后显示名称与条数。
- 导入的词库可单独开关；「删除」后需重新导入。开关、导入和删除对正在使用的键盘立即生效。

## 快捷翻译

工具栏的翻译图标打开快捷翻译条，在翻译框中输入原文，译文实时出现在外面的输入框中，点「确定」或回车保留译文，点「取消」撤掉。
中文译成学习语言，其他语言译成中文。翻译框中输入的文字不计入今日字数。

使用前需在「键盘设置 → 云端大模型」中填写 OpenAI 兼容的接口地址、模型和 API 密钥，可点「测试连接」检查。
密钥加密保存在手机上，卸载青简后无法恢复。

## 翻译选中的文字

在任意应用中选中文字后，在系统的文字选择菜单中点「青简翻译」（部分系统收在菜单的「更多」中），屏幕底部弹出翻译卡片：上方是原文，下方是译文。中文译成学习语言，其他语言译成中文；学习语言选「不显示」时译成英语。

- 复制：把译文放进剪贴板。
- 替换：用译文替换选中的文字。只在能编辑的输入框中出现。
- 翻译失败时，卡片上显示红色的「翻译失败」提示和原因，不提供复制与替换，可点「重试」。
- 点卡片外或按返回键关闭。

与快捷翻译共用「键盘设置 → 云端大模型」的设置；未填写时卡片上有「去设置」。

## 释义兜底

个别词在学习语言的释义表中没有译词，候选旁空着。在「键盘设置 → 云端大模型」中打开「释义兜底」后，这样的词上屏时交给填写的大模型补写一条译词，保存在手机上，之后再打这个词，候选旁就有译词，同样计入生词本。
发送的只有这个词本身。缺省关闭；云端大模型未填好时不能开启。学习语言选「不显示」或在私密输入框中时不发送。

## 云联想与整句补全

在「键盘设置 → 云端大模型」中打开「云联想与整句补全」后，打拼音时停顿片刻，青简把拼音和光标前后的一小段文字交给填写的大模型，它给出的词和整句排在第一个候选之后，前面带小云朵、字是青色的；展开全部候选时也一样。点整句即上屏整句。

- 九宫格同样可用，发送的是拼音行上显示的拼音。
- 「只在 Wi-Fi 下使用」缺省开启：用移动数据时不发送，快捷翻译与释义兜底不受影响。
- 缺省关闭；云端大模型未填好时不能开启。会产生流量和服务费用，私密输入框中不发送。

## 语音输入

先在「我的 → 语音识别」中选识别服务。现在可选火山引擎的豆包流式语音识别：在火山引擎控制台开通「豆包流式语音识别」，创建 API Key 填在这里，计费方式选开通的那种（小时版或并发版），可点「测试连接」检查。
这里的设置与快捷翻译用的「云端大模型」分开，互不影响；密钥加密保存在手机上。没选识别服务时，语音入口只提示还不能用。

- 三处入口：按住空格不动片刻（「键盘设置 → 按键 → 长按空格说话」，缺省开启）、工具栏的话筒、全面屏底栏的语音键。第一次使用时系统会询问是否允许青简使用麦克风。
- 说话时听出来的字直接出现在输入框里（带下划线，还没定下），说完后定下。
- 按住空格说：松手结束；滑到左边「撤回输入」上松手，这一段不要了；滑到右边那块上松手，定下后直接执行输入框的动作（聊天框里是发送）。按住空格左右滑动仍是移动光标。
- 点按进来：点下面的话筒或键盘图标说完、回到键盘；点 ⌄ 说完并收起键盘；两块弧也能点。
- 说话时录音发往火山引擎识别，会产生流量和服务费用。识别结果同打出来的字一样计入输入统计，繁体输出开着时转成繁体。

## 滑行输入

打开「键盘设置 → 按键 → 滑行输入」（缺省关闭）后，在拼音全键盘与英文键盘上，手指不抬起依次划过一个词的字母，松手就按划出的形状认出最像的词：拼音键盘认拼音（划 nihao 出「你好」，只划一个音节也行），英文键盘认英文单词。
直线上顺路经过的字母、连着两个相同的字母（hello 的 ll）不用特意绕。认出的字母像点出来的一样给候选，英文键盘不出候选时直接上屏（Shift 亮着首字母大写）。

- 只认词库里有的拼音与英文单词，词库外的新词请点按打。
- 形状几乎一样的词（to 与 too、拼音的 z 与 zh）按常用程度取，不对时退格重来或点按改。
- 打开后的第一次滑行要先准备词表，会稍慢一下。
- 九宫格、双拼、五笔、注音与日语不支持滑行。

## 导出与清空

「我的 → 高级」：

- 导出数据：把学过的词、生词本、输入统计和常用语存为一个 zip 文件，在系统的保存界面中选择存放位置。剪贴板记录与导入的词库不在其中。
- 清空学习数据：可选清空输入习惯（常选的词、造的词、英文词、个人的词序）、生词本（全部语言），或两样都清；确认后立即生效，无法恢复。输入统计、常用语、剪贴板、词库和设置不受影响。

## 外观

「我的 → 外观」：

- 主题：与电脑版相同的一组主题（青简绿、系统蓝、微信绿、樱花、大肥鱼、初音未来、波奇酱），每张卡片显示候选条与键盘的样子。选中后键盘、候选条、符号与表情面板、快捷翻译条一起换成这个主题的颜色。
- 深浅色：跟随系统、浅色或深色。樱花、大肥鱼、初音未来、波奇酱只有浅色，选深色时仍是浅色。
- 候选字号：小、标准、大、特大，候选与译词一起放大缩小，展开全部候选时也一样；字号调大时候选条随之变高。键面上的字不变。

页面顶部的预览按当前的主题、深浅色和字号显示。

## 键盘设置

在青简应用的「我的 → 键盘设置」中修改，开着的键盘立即生效：

- **中文键盘**：选择拼音 26 键、九宫格、双拼、五笔或注音；双拼可选方案，五笔可与拼音混输。
- **学习**：
  - 学习语言，换了键盘上的译词立即换；选「不显示」时不显示译词，也不记生词。
  - 学习输入习惯：关闭后不再记住常选的词和新造的词，已学的继续参与排序。
- **输入**：
  - 模糊音：可选 z = zh、c = ch、s = sh、n = l、f = h、l = r、an = ang、en = eng、in = ing，见 [模糊音与输入方案](../input/fuzzy-and-shuangpin.md)。九宫格暂不支持。
  - 中文用全角标点：关闭后中文键盘的逗号、句号、问号等输出半角。数字后面的点始终是半角。
  - 分次选词先不上屏：缺省开，见上文「候选与译词」；关闭后选了就上屏。
  - 打拼音时也给英文词：输入 `hello`、`compa` 时候选中出现英文词；可再选「中文排在英文词前面」。
  - 英文键盘给候选：关闭后英文键盘的字母直接上屏，不出候选。
  - 繁体字形：功能面板「繁体」开启时使用的字形，可选台湾、香港或通用。台湾与香港的字形取舍不同（這裡 / 這裏），只换字形，不换用语。
  - 词库：进入词库页，见上文。
- **尺寸**：键盘高度，也可点工具栏的 ↕ 直接在键盘上拖动；全面屏适配开启时，手势条两侧各放一个键。
- **按键**：按键震动、按键气泡、换语言时保留中文、长按空格说话（见上文「语音输入」）、滑行输入（见上文「滑行输入」）。

## 尚未支持

不联网的本机语音识别、自己编写的主题。
